# Seeder

แยกให้ชัดว่าอันไหนต้องรันจริงบน production อันไหนห้ามรัน

| ไฟล์ | รันบน production | หมายเหตุ |
|---|---|---|
| `001_seed_admin_user.sql` | ✅ ต้องรัน | บัญชีแอดมินตั้งต้น — **เปลี่ยนรหัสผ่านทันทีหลังเข้าครั้งแรก** |
| `9xx_sample_*.sql` | ❌ ห้ามรัน | ข้อมูลตัวอย่างสำหรับทดสอบเท่านั้น |

**ข้อมูลตัวอย่างต้องมี 50-100 แถวขึ้นไปสำหรับตารางหลัก** ไม่ใช่ 3 แถว
seed 3 แถวแล้วจะไม่มีใครเห็นว่า pagination พัง การเรียงผิด หรือ query ช้า จนกว่าจะขึ้นใช้จริง

**ห้ามใส่ข้อมูลจริงของลูกค้าลง seeder** — รหัสผ่านจริง ชื่อจริง เบอร์จริง ใช้ข้อมูลสมมติเท่านั้น

หลังรัน seeder ‼️ **ต้องอ่านข้อมูลกลับมาเทียบว่าภาษาไทยไม่เพี้ยน ผ่าน PDO ไม่ใช่ดูจาก console**
console บน Windows แสดงภาษาไทยไม่ได้อยู่แล้ว ทำให้แยกไม่ออกว่าข้อมูลเสียจริงหรือแค่แสดงผลเพี้ยน
