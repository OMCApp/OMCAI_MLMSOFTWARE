# ข้อสงสัย / ข้อมูลจริงที่ยังไม่มี

ทุกข้อด้านล่างทำงานต่อได้โดยไม่ต้องรอ — ใช้ค่ากลางที่ปลอดภัย และเก็บไว้ใน CMS ให้แก้ได้เองเมื่อมีข้อมูลจริง

## ข้อมูลจริงที่ต้องได้จากผู้ใช้ (ไม่มี = ซ่อนส่วนนั้นหรือใช้ข้อความกลาง)
- [ ] ตัวเลขยืนยันได้: ปีที่ก่อตั้ง/ประสบการณ์ · จำนวนโปรเจค · จำนวนผู้ใช้ — **แบบอ้างอิงมี 10+ ปี / 200+ / 100,000+ / 99.9% / 24/7 แต่ยังไม่มีหลักฐาน → ไม่แสดงจนกว่าจะยืนยัน** (แก้ใน CMS)
- [ ] โลโก้ลูกค้าที่ได้รับอนุญาต — แบบอ้างอิงมี J&C, NUTRIPLUS ฯลฯ ซึ่งไม่ทราบว่าจริงไหม → **ไม่แสดง**
- [ ] testimonial จริง (ชื่อ/ตำแหน่ง/ข้อความ/รูป ที่ได้รับอนุญาต) → ไม่แสดงจนกว่าจะมี
- [ ] case study จริง → หน้า `/portfolio/` แสดงสถานะ "กำลังรวบรวม" + CTA
- [ ] ภาพทีม / office / ผู้บริหารจริง — ใช้ภาพจากเว็บเดิมที่เป็นของ OMC ก่อน · ไม่ใช้ภาพบุคคลสต็อกแอบอ้างเป็นทีม
- [ ] เบอร์โทร · LINE OA · อีเมลรับ lead · ที่อยู่บริษัท · เลขทะเบียนนิติบุคคล — ดึงจากเว็บเดิมก่อน
- [ ] แผนรายได้ที่ระบบรองรับจริง (Board / Stair Step รองรับจริงไหม)
- [ ] ราคา/แพ็กเกจ — ไม่มี → หน้า Pricing เป็น "ขอใบเสนอราคา" + ปัจจัยที่มีผลต่อราคา ไม่ใส่ตัวเลข
- [ ] Search Console export · DB `omc_web` export (ไม่บังคับ — ย้ายเนื้อหาจาก HTML เว็บจริงได้)
