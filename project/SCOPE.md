## ไม่อยู่ในขอบเขต
- `lead_attempts` ไม่มี soft delete โดยตั้งใจ — เป็นตัวนับการส่งฟอร์มต่อ IP (เหมือน `login_attempts`) ลบแถวเก่ากว่า 7 วันทิ้งจริง ไม่มีหน้าจัดการ
- บทความภาษาอังกฤษ/จีน — บทความเดิม 36 เรื่องเป็นภาษาไทยเท่านั้น (ห้ามแปลด้วยเครื่อง) · `/en/blog/` `/zh/blog/` เปิดเองเมื่อมีบทความแปลเผยแพร่
- ระบบ MLM จริง (สมาชิก/คอมมิชชัน) — เว็บนี้คือเว็บขาย ภาพ dashboard เป็น mockup ที่ทำจาก HTML/CSS
- ตัวเลข/โลโก้ลูกค้า/รีวิว ที่ยังไม่มีหลักฐาน — ช่องมีใน CMS แต่ซ่อนจนกว่าจะใส่ของจริง
- การสลับ production (DNS / document root) — ทำเมื่อผ่าน SEO Migration Gate และผู้ใช้ยืนยัน
- ระบบส่งอีเมลการตลาด / CRM เต็มรูปแบบ — มีแค่ lead inbox + export
- `/not-found` (บันทึก 404) — ระบบเขียนเองทุกครั้งที่มีคนเข้า URL ที่ไม่มี · หน้าจัดการมีแค่ดู · "สร้าง redirect" (ไปที่ /redirects) · "ซ่อน" (DELETE) — ไม่มีเพิ่ม/แก้ด้วยมือโดยตั้งใจ
- `/backups` — ไฟล์สำรองแก้ไขไม่ได้ (สร้าง · ดาวน์โหลด · ลบ) · **กู้คืนผ่าน CLI เท่านั้น** ไม่มีปุ่มบนเว็บโดยตั้งใจ (ขั้นตอนใน DEPLOY.md)
- `/support-requests` — คำขอมาจากปุ่มแจ้งปัญหา (POST /admin/support) · หน้าแอดมินดู/เปลี่ยนสถานะ · ไม่ลบเพื่อเก็บประวัติ (ของจากมาตรฐาน)
- โน้ตของ lead (`lead_notes`) — เพิ่มได้อย่างเดียว ไม่มีแก้/ลบ และไม่มี `deleted_at` โดยตั้งใจ: ประวัติการติดต่อลูกค้าต้องครบ
